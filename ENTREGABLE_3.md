# Entregable 3: CMakeLists

## Linux

Para compilar hacer:

`mkdir build && cd build`

`cmake ..`

`make`

y para ejecutar:

`./proyectoDCA` o `make run`

## Windows

Ejecutar el fichero CMakeLists.txt desde visual studio

o

Para compilar hacer:

`mkdir build-windows && cd build-windows`

`cmake --build . --config Release`

`cd Release`

y para ejecutar:

`./proyectoDCA.exe`
